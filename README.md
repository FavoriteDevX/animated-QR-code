## 🚀 How to Use the Web App

Using the tool is super easy. Just follow these steps:

1. **Enter your link:** Type or paste your URL (like your GitHub profile, portfolio, or social media) into the input box at the top.
2. **Pick a style:** Click on one of the three animation buttons:
   * 👾 **Retro Pulse:** Classic pixel blinking effect.
   * 🟢 **Matrix Rain:** Cyberpunk green digital rain code.
   * 🌊 **Sine Wave:** Smooth moving wave transitions.
3. **Generate:** Click the **"Generate Code"** button to see your new animated QR code live on the screen.
4. **Test it:** Point your smartphone camera at the screen—it will scan and open your link instantly!
5. **Download:** Click the **"Download WebM"** button. The app will record a perfect 3-second loop of the animation and save it directly to your device.

## 📱 Why does it still scan?
QR codes have a built-in "Error Correction" system. This app uses the highest level available (Level H), which allows up to 30% of the code to change or move. By keeping the three main corner squares completely static, your phone can still lock onto the code and read the data perfectly through the animations!
